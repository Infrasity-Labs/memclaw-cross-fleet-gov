# Contributing

Thanks for your interest in improving this project.

## How to Contribute

1. Fork the repository.
2. Create a feature branch.
3. Make focused, testable changes.
4. Update README/docs when behavior changes.
5. Open a pull request with:
- clear summary
- why the change is needed
- verification steps and expected output

## Pull Request Checklist

- [ ] Change is scoped and documented.
- [ ] Security impact considered.
- [ ] Governance behavior still enforced.
- [ ] Verification steps included.

## Issues

Use issues for bugs, docs gaps, and enhancement proposals.
